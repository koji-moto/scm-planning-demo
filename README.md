# Stockscape — SCM Executive Demo

冷凍食品メーカー兼卸売業の将来のSCM業務をイメージした、**経営層・管理職・IT部門向けのPoC**です。実運用システムではなく、「将来のSCM業務の完成イメージ」を経営会議などで共有し、業務やシステムの構想を具体化するためのデモです。

表示する会社、工場、倉庫、商品、数量、金額、アラートはすべて架空のダミーデータです。実在する会社・商品・顧客データは一切使用していません。

## デモで確認できること

- 供給充足率、販売計画、在庫金額、欠品・過剰在庫、製造・発注、工場キャパをまとめた経営KPI
- 関西・関東・北海道・九州の4倉庫を横断するSCM状況
- 経営・SCM部門が優先して対応すべきアラートと、ルールベースの経営コメント
- 自社製造品（冷凍うどん、冷凍ラーメン、冷凍パスタ）と仕入品（冷凍餃子、冷凍コロッケ、豚まん）の8週間需給シミュレーション
- 泉工場・富工場の週別製造計画、最大能力、キャパ使用率
- 仕入品の発注予定、入荷週、リードタイム、発注アラート
- 商品・倉庫を切り替えられる未来在庫と安全在庫の推移グラフ

## 在庫計算

自社製造品は次の式を使用します。

```text
週末在庫 = 前週末在庫 + 製造数量 + 倉庫間入庫 - 販売数量 - 倉庫間出庫
```

仕入品は「製造数量」を「入荷数量」として同じロジックで計算します。安全在庫未満は黄色、在庫0未満は赤色で表示します。

## 起動方法

追加パッケージや外部サービスは不要です。Python 3で静的Webサーバーを起動します。

```bash
npm start
```

ブラウザで <http://localhost:8000> を開いてください。GitHub Pagesでもリポジトリ直下をそのまま公開できます。

## テスト

Node.js 18以上で実行してください。

```bash
npm test
node --check app.js
node --check inventory.js
```

## PoCの範囲

このリポジトリだけで動作するフロントエンドデモです。kintone API、基幹システム、外部API、外部DB、ログイン認証、AI API、本格的な賞味期限・ロット管理、データ保存は実装していません。画面内のAIコメントは固定ルールベースのダミー表示です。

| ファイル | 役割 |
| --- | --- |
| `index.html` | ダッシュボード、テーブル、グラフの画面構造 |
| `styles.css` | 経営会議向けのレイアウト、配色、レスポンシブ表示 |
| `inventory.js` | 架空データ、8週間在庫計算、ステータス判定 |
| `app.js` | KPI・各計画の描画、選択操作、Canvasグラフ |
| `test/inventory.test.js` | 在庫計算と警告判定の自動テスト |
